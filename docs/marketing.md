# Marketing surface

The public landing page lives in `src/app/(marketing)` and remains public for signed-in users. `PenLanding` (`src/components/marketing/pen-landing.tsx`) renders it; its layout scopes the Manrope/Inter display fonts and `pen-landing.module.css`, and the GSAP/Lenis motion layer lives in `src/components/marketing/motion`. The brand is the shared `Wordmark` (í symbol plus typeset „Investník“), used by auth, onboarding, legal pages and the app shell; the only raster brand files are the generated icons and social image listed in [brand.md](brand.md). Product screens use the quieter shared design system.

The page follows the 2026–27 strategy in [product-direction.md](product-direction.md): it prepares a beginning investor for a first investment and for sticking to their own plan. Its sections are the hero with a read-only sample from the published debt lesson (0.1.2), the path through levels 0–2 to an IPS and the crisis exercise, module outputs, Lab process feedback, trust (dated facts, tax-adviser review, no recommendations) and the closing call to action. The one primary action, „Začít vstupním testem“, opens `/onboarding` (preferences and the five diagnostic questions), which keeps the #355 funnel intact: the landing view beacon counts the visit and the new guest or account counts the start.

Every status on the page must match the published inventory: lessons in `src/features/lessons/registry.ts` (`authoredLessons` vs. `draftLessons`) and placements in `src/features/learning/curriculum.ts`. Unpublished content says „připravujeme“; the page names no brokers, banks or funds and states no lesson, user or outcome counts. `landing-inventory.test.ts` fails when a lesson the page calls „připravujeme“ is published, so the copy is updated in the same change.

Sign-up/sign-in actions use the existing authentication routes. Protected Learn/Lab links retain authentication gates and disable speculative lab prefetch. Explore demo uses the existing anonymous identity and server seed; it does not share a login or overwrite an existing demo portfolio. Mobile navigation uses native `details` semantics.

Landing illustrations live in `public/marketing` as WebP, sized to about twice their largest rendered width (q≈75) and served through `next/image`. Re-export new artwork the same way rather than committing full-resolution PNGs; the brand design source is `investi-design.pen`, not a file in `public/`. Example outcomes retain their educational disclosure, and illustrations are never represented as live market data. Display fonts stay scoped to marketing; product typography uses the shared theme fonts. Bright brand fills require readable navy/deep-blue text rather than blindly applying white body text.

Semantic sections, one H1, skip link, visible focus, responsive disclosure navigation, pending/error demo feedback, and reduced-motion styles are part of the current contract. Text must reflow when enlarged.

Run `BROWSER_CHANNEL=chrome npm run test:marketing-browser` against a fresh local app/database. It covers six widths and 200% root text, loaded artwork, static allocation semantics, mobile destinations, keyboard menu/skip link, metadata, reduced motion, demo failure/retry/session reuse/isolation, and protected routes. Output stays in `/tmp/investi-marketing-qa` unless explicitly overridden. Physical-device and assistive-technology checks remain manual.
